# Assets Folder

This folder is for storing images, icons, and other static assets that you want to use in the application.

## Usage

You can upload files here and reference them in your components using:

```javascript
// For images
import myImage from '../assets/my-image.png'

// Or directly in templates
<img src="/src/assets/my-image.png" alt="Description" />
```

## Supported File Types

- Images: .png, .jpg, .jpeg, .gif, .svg, .webp
- Icons: .svg, .ico
- Other assets as needed

## Organization

Feel free to create subfolders to organize your assets:
- `icons/` - for icon files
- `images/` - for photos and illustrations  
- `logos/` - for brand assets
- etc.
