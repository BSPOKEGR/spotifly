# Parcel Thumbnails

This folder contains thumbnail images for each parcel showing their satellite view.

## File Naming Convention

Name your thumbnail files using the parcel ID:
- `parcel-1.jpg` - for Olive Grove North
- `parcel-2.jpg` - for Mediterranean Plot  
- `parcel-3.jpg` - for Southern Orchard
- `parcel-4.jpg` - for Heritage Grove
- `parcel-5.jpg` - for Valley Fields

## Image Requirements

- **Format**: JPG, PNG, or WebP
- **Size**: Recommended 300x200 pixels
- **Content**: Satellite/aerial view of the specific parcel
- **Quality**: High enough to show parcel boundaries and features

## Usage

Once uploaded, the thumbnails will automatically appear in the parcel cards on the dashboard.

## How to Upload

1. Take screenshots from your mapping software showing each parcel
2. Crop and resize to 300x200 pixels
3. Save with the correct filename (parcel-1.jpg, parcel-2.jpg, etc.)
4. Upload to this folder
